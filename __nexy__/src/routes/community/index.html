# Community Welcome to the Nexy community. Here you can find resources to help you get started, contribute, and connect with other developers. ## Get involved - **Report bugs** — open an issue on [GitHub](https://github.com/anomalyco/nexy/issues) - **Request features** — start a discussion or open a feature request - **Contribute code** — read the [contributor guide](/community/contributor) and submit a PR - **Ask questions** — open a GitHub discussion ## Project governance Nexy is maintained by a small core team. See the [governance page](/community/governance) for details on how decisions are made.
