# nx инициализация

Инициализирует каркас проекта Nexy в существующем каталоге. Используйте это, чтобы добавить Nexy в существующий проект Python.

{% raw %}```bash
nx init
```{% endraw %}

---

## Что он создает

- `nexyconfig.py` — основной файл конфигурации
- `vite.config.ts` — конфигурация Vite (если клиентские компоненты включены)
- `__nexy__/` — скомпилированный выходной каталог (добавлен в `.gitignore`)

---

## Примечания

- `nx init` интерактивный — запрашивает настройки проекта.
- Используйте `nx new`, если вы хотите указать имя проекта и параметры с самого начала.

---

## Пример

{% raw %}```bash
# Initialize in the current directory
nx init
```{% endraw %}

---

## Псевдоним

`nx i`
