# Использование компонентов

Компоненты — это файлы `.nexy` в `src/components/`, которые вы импортируете на страницы и другие компоненты.

## Создание компонента

Компонентом является любой файл `.nexy`. Самый простой компонент не имеет фронтальной части — только HTML:

{% raw %}```nexy
<!-- src/components/Hello.nexy -->
---
---
<h1>Hello Nexy!</h1>
```{% endraw %}

Но у большинства компонентов есть реквизиты, логика и шаблон.

## Импорт компонентов

Используйте синтаксис импорта компонентов Nexy, который поддерживает относительные пути и настроенные псевдонимы:

{% raw %}```nexy
---
from "./Card.nexy" import Card
from "./Header.nexy" import Header
from "@components/Button.nexy" import Button
---
```{% endraw %}

Путь импорта указывается относительно текущего файла. `"@/` по умолчанию соответствует `src/` (или тому, что вы настроите в `useAliases`).

**Почему такой специальный синтаксис?** Потому что во время сборки компилятору необходимо знать, какие теги PascalCase являются компонентами, а какие — неизвестными элементами HTML. Санитайзер преобразует эти импортированные данные до того, как их увидит синтаксический анализатор AST Python, поэтому они никогда не вызывают синтаксических ошибок.

## Компоненты рендеринга

В шаблоне используйте импортированное имя в качестве HTML-тега:

{% raw %}```nexy
---
from "./Card.nexy" import Card
---
<Card title="Hello" count={5} />
```{% endraw %}

Компилятор преобразует теги PascalCase в вызовы функций Jinja2:

| Шаблон | Скомпилированный вывод |
|----------|----------------|
| `<Card />` | `{{ '{{' }}Card() {{ '}}' }}` |
| `<Card title="Hi" />` | `{{ '{{' }} Card(title="Hi") {{ '}}' }}` |
| `<Card count={5} />` | `{{ '{{' }} Card(count=5) {{ '}}' }}` |
| `<Card>content</Card>` | `{{ '{%' }} call Card() {{ '%}' }}content{{ '{%' }} endcall {{ '%}' }}` |

**Требования к именованию**: имена компонентов **должны** начинаться с заглавной буквы. Если вы используете нижний регистр, компилятор воспринимает его как обычный элемент HTML и не вызывает функцию компонента. Это соответствует соглашению веб-платформы (пользовательские элементы должны иметь дефис; PascalCase зарезервирован для компонентов платформы).

## Передача реквизита

{% raw %}```nexy
---
from "./Card.nexy" import Card
---
<!-- Static string -->
<Card title="Hello" />

<!-- Dynamic Jinja2 expression -->
<Card title="{{ page_title }}" />

<!-- Unquoted value (expression, not string) -->
<Card count={5} active={true} items={["a", "b"]} />

<!-- Mixed -->
<Card title="{{ page_title }}" count={items|length} />
```{% endraw %}

**Правила передачи атрибутов**:

| Синтаксис | Тип значения | Вывод шаблона |
|--------|-----------|----------------|
| `title="Hello"` | Строка | `Card(title="Hello")` |
| `title="{{ '{{' }} var {{ '}}' }}"` | Выражение Jinja2 | `Card(title=var)` |
| `count={5}` | Выражение Python | `Card(count=5)` |
| `active=true` | Ключевое слово (Python bool) | `Card(active=True)` |
| `items={["a"]}` | Выражение Python | `Card(items=["a"])` |

Значения без кавычек, соответствующие литералам Python (`true`, `false`, `none`, числа), передаются как есть. Все остальное — строка.

**Попался**: `count={0}` передает целое число 0. `count="0"` передает строку `"0"`. В шаблонах Jinja2 `{{ '{%' }} if count {{ '%}' }}` оценивается по-разному для `0` (ложный) и `"0"` (правдивый). Используйте `{0}`, когда вам нужен числовой ноль.

## Слот / Дети

Компоненты, которые обертывают контент, используют `<slot />`, чтобы определить, куда идут дочерние элементы:

{% raw %}```nexy
<!-- Card.nexy -->
---
title:prop[str] = ""
---
<div class="card">
  {{ title }}
  <div class="card-body">
    <slot />
  </div>
</div>
```{% endraw %}

{% raw %}```nexy
<!-- Usage -->
---
from "./Card.nexy" import Card
---
<Card title="My Card">
  <p>This appears inside the slot.</p>
</Card>
```{% endraw %}

**Как работают слоты**: компилятор помещает дочерние элементы в блок `{{ '{%' }} call {{ '%}' }}`. Компонент получает их как функцию `caller`. `<slot />` вызывает `caller()` и выводит результат.

**Ограничения**:
- Только один безымянный слот на компонент
- Нет слотов с ограниченной областью действия (вместо этого передайте функции как реквизиты)
- Слоты работают только в файлах `.nexy`, а не в необработанных шаблонах Jinja2.

## Самозакрытие против упаковки

Самозакрывающиеся компоненты (без детей):

{% raw %}```nexy
<Header title="Blog" />
<Separator />
<Spacer size={16} />
```{% endraw %}

Обертывание компонентов (с дочерними элементами):

{% raw %}```nexy
<Card title="Post">
  <p>Content here</p>
</Card>

<Layout>
  <Header />
  <main>Page content</main>
  <Footer />
</Layout>
```{% endraw %}

Компилятор обнаруживает самозакрывающиеся теги (`<Card />`) и теги с дочерними элементами (`<Card>...</Card>`) и генерирует соответствующий синтаксис Jinja2.

## Ранний возврат/условный рендеринг

Поскольку компонент является функцией Python, вы можете вернуться к началу темы:

{% raw %}```nexy
---
title:prop[str] = ""
if not title:
    print("Warning: Card rendered without title")
    # Return early — the template still runs but title is empty
---
<div class="card">
  {{ title }}
  <slot />
</div>
```{% endraw %}

Для условного рендеринга в шаблоне используйте Jinja2 `{{ '{%' }} if {{ '%}' }}`:

{% raw %}```nexy
---
show_header:prop[bool] = true
---
{% if show_header %}
  <header>
    <slot />
  </header>
{% endif %}
```{% endraw %}

## Лучшие практики

- **Один компонент на файл** — четкое название, легко найти
- **Держать шаблоны до 50 строк** — если они длиннее, извлекайте подкомпоненты.
- **Используйте реквизиты вместо жесткого кодирования** — делает компоненты пригодными для повторного использования.
- **Именуйте файлы в PascalCase** — `BlogCard.nexy`, а не `blog_card.nexy`
- **Реквизиты по умолчанию для необязательных значений** — `title:prop[str] = ""`, а не `title:prop[str]`
