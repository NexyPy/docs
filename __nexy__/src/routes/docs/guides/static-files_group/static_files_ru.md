# Статические файлы

Nexy обслуживает статические файлы из каталога `public/` в корне вашего проекта.

## Как это работает

Любой файл, помещенный в `public/`, обслуживается по корневому URL-адресу:

{% raw %}```text
public/
├── logo.svg           →  /logo.svg
├── images/
│   └── hero.jpg       →  /images/hero.jpg
├── fonts/
│   └── inter.woff2    →  /fonts/inter.woff2
└── robots.txt         →  /robots.txt
```{% endraw %}

Никакой конфигурации не требуется. Файлы в `public/` обслуживаются автоматически.

## Каталог ресурсов

Для скомпилированных ресурсов (CSS, JS из Vite) используйте каталог `assets/` или настройте вывод в `vite.config.ts`. Nexy монтирует их по адресу `/assets/`.

## Ссылка на статические файлы

В шаблонах `.nexy`:

{% raw %}```nexy
<img src="/logo.svg" alt="Logo" />
<link rel="stylesheet" href="/styles/global.css" />
```{% endraw %}

В интерфейсе Python или обработчиках маршрутов пути указываются относительно корня проекта.

## Производство

Во время `nx build` каталог `public/` копируется в `__nexy__/public/`. Ваш производственный сервер обслуживает эти файлы напрямую — компиляция не требуется.
